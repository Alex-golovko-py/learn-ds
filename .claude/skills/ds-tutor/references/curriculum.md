# Программа обучения: Python → Data Science

Порядок блоков менять нельзя — каждый опирается на предыдущий. Порядок тем внутри блока и глубину подстраивай под ученика.

Темп ученика: 1–2 часа в день. Полный путь ≈ 12–15 месяцев. Цель — уверенный джун с готовностью к миддлу и портфолио из сквозных проектов.
